# 슬기로운에듀라이프 합동 비서실 (UI 미리보기)

슬기로운 에듀라이프(주)의 **합동 비서실** 오피스 화면입니다.
지금은 **미리보기 모드**로, 실시간 DB(파이어베이스) 연결 전의 화면 구성 확인용 정적 페이지입니다.

- 주소: https://etihw88.github.io/pickle-office/
- 파일: `index.html` 단일 파일 (CSS/JS 포함, 외부 의존은 Google Fonts 뿐)

## 화면 구성

1. **오피스 맵** — ① 대표실(백승리 대표님) · ② 회의실(피클 합동 브리핑) · ③ 작업실(입찰·서류·뉴스 데스크)
   방을 누르면 하양이 캐릭터가 그 방으로 이동하고 상태 문구가 바뀝니다.
2. **참여 피클** — 하양이(대기 중 · 👑 메인 비서) + 초대 대기 슬롯(가족·동료 피클 연결 시 합류)
3. **비서실 채팅(미리보기)** — 상단 `미리보기 모드 (실시간 DB 연결 전)` 배지, `@하양이` 멘션 버튼,
   입력창. 보낸 메시지에 하양이가 예시 응답을 돌려주며, 내용에 따라 방도 옮겨 다닙니다.

## 다음 단계 (실시간 연결 시)

- 미리보기 배지 제거
